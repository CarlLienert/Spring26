Using #8, this is equivalent to:

\[\frac{1}{2^n}< \frac{1\cdot3\cdot5\cdots(2n-1)}{2\cdot4\cdot6 \cdots (2n)} < 1.\]

Consider the fraction as:

\[\left(\frac{1}{2}\right)\left(\frac{3}{4}\right)\left(\frac{5}{6}\right)\cdots\left(\frac{2n-1}{2n}\right).\]

Each of these fractions is less than one, so the product is less than one, which gives the righthand inequality.

With the exception of \(\frac{1}{2}\), each of these fractions is greater than \(\frac{1}{2}\). There are \(n\) factors so the product is greater than \(\frac{1}{2^n}\).
